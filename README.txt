MY DIGITAL PLAYGROUND
=====================
Open index.html in a browser or publish this folder with GitHub Pages.

All screenshot images are stored in the same folder as index.html.
The image paths in index.html are relative filenames (for example,
happy-18th-anniversary-1.webp), not paths inside an assets folder.

All five project entries and all original screenshot assets are retained.


ABOUT PAGE UPDATE
-----------------
A separate creator profile is available at about.html.
The homepage navigation now includes an ABOUT link to that page.
The supplied creator image is stored beside index.html as 24099.png
and is referenced from about.html using ./24099.png.

The About page shares the site's lavender, silver, cyan, mint, gold,
and pearl palette. Its night mode uses a violet-tinted theme and shares
the mdp-theme preference with the homepage. It includes responsive
layouts, reduced-motion support, and scroll-triggered section reveals.

To run locally, extract the ZIP and open index.html. Keep all files in
the extracted root folder; do not move or rename the screenshots or
24099.png. For GitHub Pages, publish the extracted folder as-is.
